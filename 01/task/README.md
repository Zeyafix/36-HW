# Список книг для чтения

Читатель хочет сохранить книги, которые планирует прочитать. Напишите самостоятельную программу в `main.py`. Сначала она спрашивает имя владельца списка, затем количество книг. Для каждой книги последовательно запросите название, автора и количество страниц.

Программа запускается из папки с `main.py`.

Имя владельца, названия и имена авторов непустые; возможны пробелы, кавычки и буквы разных языков. Книг может быть от 0 до 20, страниц в каждой книге — от 1 до 10000, без дробной части. Ввод всегда соответствует условию; проверять ошибки ввода не нужно. Одинаковые книги допустимы: сохраняйте каждую введённую запись.

Сохраните данные в `data/reading_list.json` в папке `data` рядом с `main.py`. Если папки `data` нет, программа должна создать её. Если файла нет, создайте его; если он уже существует, полностью замените содержимое списком текущего запуска.

В результате должны быть только поля `owner` и `books`. Внутри `books` сохраните книги в порядке ввода. У каждой книги должны быть только `title`, `author`, `pages` и `finished`. Количество страниц хранится как число, а `finished` у каждой новой записи равно JSON-значению `false`: книги пока только запланированы. Если книг нет, сохраните `books` со значением `[]`, сохранив имя владельца.

Используйте UTF-8 и сохраняйте введённый текст без потерь. Отступы, порядок полей внутри объектов и представление букв напрямую или через JSON-последовательности `\u` можно выбрать самостоятельно.

Перед каждым запросом, включая запросы о каждой следующей книге, нужна подсказка на английском. После сохранения выведите сообщение на английском с именем файла. Формулировки в примере — один из вариантов; другой текст допустим.

Пример диалога:

```text
Enter list owner: Maya
Enter number of books: 2
Enter book title: The Hobbit
Enter book author: J. R. R. Tolkien
Enter page count: 310
Enter book title: Coraline
Enter book author: Neil Gaiman
Enter page count: 192
Reading list saved to data/reading_list.json
```

Содержимое `data/reading_list.json` после этого запуска:

```json
{
  "owner": "Maya",
  "books": [
    {"title": "The Hobbit", "author": "J. R. R. Tolkien", "pages": 310, "finished": false},
    {"title": "Coraline", "author": "Neil Gaiman", "pages": 192, "finished": false}
  ]
}
```
