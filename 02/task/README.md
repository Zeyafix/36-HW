# Сведения о доставке

Курьер получил файл [delivery.json](data/delivery.json) с данными заказа. Напишите самостоятельную программу в `main.py`, которая читает файл и показывает номер заказа `order_id`, имя получателя `recipient.name`, город `recipient.address.city`, улицу с номером дома `recipient.address.street` и все позиции из `items`: название `name` и количество `quantity`.

Программа запускается из папки с `main.py`.

Для каждой позиции должна быть отдельная строка с названием и количеством. Сохраните порядок позиций из файла, включая повторяющиеся названия. Если список позиций пуст, вместо строк позиций выведите сообщение на английском о том, что товаров нет. Сведения о заказе и получателе при этом всё равно нужно показать. Подсчитывать общую стоимость или количество товаров не требуется.

Файл находится в папке `data` рядом с `main.py`. Файл существует и содержит корректный JSON в UTF-8 с указанной структурой. Текстовые значения непустые, могут содержать пробелы, кавычки и буквы разных языков. Количество каждой позиции — от 1 и выше, без дробной части. Проверять ошибки данных не нужно.

Читайте актуальные значения из файла при каждом запуске. Не меняйте исходный файл и не создавайте новые файлы. Ввод с клавиатуры не нужен.

Для приложенного файла результат может выглядеть так:

```text
Order: D-104
Recipient: Sam Lee
City: Baku
Street: Garden Street 18
Item: Notebook | Quantity: 3
Item: Marker | Quantity: 2
```

Если в этом же файле `items` заменить на `[]`, пример результата:

```text
Order: D-104
Recipient: Sam Lee
City: Baku
Street: Garden Street 18
No items in this delivery
```
