# Отчёт о расходах

В файле [expenses.json](data/expenses.json) записаны бюджет `budget` и список расходов `expenses`. У каждого расхода есть категория `category` и сумма `amount`. Напишите самостоятельную программу в `main.py`, которая читает эти данные и сохраняет отчёт в другой файл — `data/report.json`.

Программа запускается из папки с `main.py`.

В отчёте должны быть только три поля:

- `total` — сумма всех расходов.
- `remaining` — сколько осталось от бюджета после всех расходов. Если расходы больше бюджета, значение должно быть отрицательным.
- `categories` — список итогов по категориям. У каждого итога только два поля: `category` и `total`, сумма расходов этой категории.

Одинаковые категории нужно объединить, даже если их записи не стоят рядом. Категории с разным регистром считаются разными: `Food` и `food` не объединяются. Расположите категории в порядке их первого появления в исходном списке. Категорию с итогом `0` тоже нужно сохранить.

Пример `data/expenses.json`:

```json
{
  "budget": 1000,
  "expenses": [
    {"category": "Food", "amount": 250},
    {"category": "Transport", "amount": 80},
    {"category": "Food", "amount": 120}
  ]
}
```

Для этих данных `data/report.json` должен содержать:

```json
{
  "total": 450,
  "remaining": 550,
  "categories": [
    {"category": "Food", "total": 370},
    {"category": "Transport", "total": 80}
  ]
}
```

Оба файла находятся в папке `data` рядом с `main.py`. Исходный файл существует и содержит корректный JSON в UTF-8. Бюджет и расходы заданы в целых денежных единицах от 0 и выше, без копеек. Категории непустые; возможны пробелы, кавычки и буквы разных языков. Проверять ошибки данных не нужно.

При пустом списке расходов сохраните `total` со значением `0`, `remaining` со значением бюджета и `categories` со значением `[]`.

Не меняйте исходный файл. Если файла результата нет, создайте его; если он есть, полностью замените прежнее содержимое. Сохраните результат в UTF-8. Отступы, порядок полей внутри объектов и представление букв напрямую или через JSON-последовательности `\u` можно выбрать самостоятельно.

Ввод с клавиатуры не нужен. После сохранения выведите сообщение на английском с именем файла, например:

```text
Expense report saved to data/report.json
```

Это пример формулировки; другой текст сообщения допустим.
